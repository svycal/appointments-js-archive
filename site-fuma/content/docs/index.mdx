## REST API

The SavvyCal Appointments API adheres to [REST](http://en.wikipedia.org/wiki/Representational_State_Transfer) conventions. It communicates in JSON and authenticates with [bearer tokens](/authentication). New fields may be added to existing payload types as the API expands.

The full OpenAPI specification is at [https://api.savvycal.app/v1/spec](https://api.savvycal.app/v1/spec).
